# SMSspamcollection
SMS Spam Collection Using Machine Learning

This project detects whether an SMS message is Spam or Normal using Machine Learning.

Tools Used: Python, Jupyter Notebook, Pandas, NumPy, Seaborn and Scikit-learn.

Algorithms Used:

- Logistic Regression
- Decision Tree
- Random Forest

Result: Random Forest achieved the highest accuracy of 97.49%.

Conclusion: This project helped me understand data preprocessing, TF-IDF, model training and prediction using Machine Learning.
